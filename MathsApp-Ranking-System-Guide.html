Ranking & Quiz Point System

A complete reference guide covering quiz scoring, game outcomes, rank structure, star progression, protection shields, bonus boosts, and profile XP.

Version 2.0  ·  May 2026
1 Quiz Scoring (Per Game)

Every quiz contains exactly 8 questions. Each question allows up to 2 answer attempts. Points are awarded per question based on how many attempts were needed:

Attempt Result Points Awarded Notes
Correct on 1st attempt +100 pts Full marks
Correct on 2nd attempt +50 pts Half marks
Wrong on both attempts 0 pts No marks
Maximum Score = 8 questions × 100 pts = 800 pts Game Percent = (Game Points ÷ 800) × 100
Example: A player gets 6 questions correct on the first try and 1 correct on the second try, and misses 1. Score = (6 × 100) + (1 × 50) + (1 × 0) = 650 pts = 81.25%
2 Game Outcomes

The game percentage determines the outcome, which drives all rank star changes and rewards:

Outcome Score Threshold Min Points Rank Stars XP Coins
🌟 Flawless ≥ 87.5% ≥ 700 pts +2 +200 +5
✅ Victory ≥ 62.5% ≥ 500 pts +1 +120 +3
🤝 Draw ≥ 37.5% ≥ 300 pts 0 +60 +1
❌ Defeat < 37.5% < 300 pts −1 (see SPP) +30 0
Note: XP is always awarded regardless of outcome, so every game contributes to your profile level even on a Defeat.

3 Rank Structure

4 Promotion & Demotion

▲ Promotion (Moving Up)

When your stars in a tier reach the maximum, you automatically promote to the next tier or rank:

  • Tier 3 fills up → promotes to Tier 2, 0 stars
  • Tier 2 fills up → promotes to Tier 1, 0 stars
  • Tier 1 fills up → promotes to next rank, Tier 3, 0 stars
  • Legend Tier 1 fills up → becomes Legendary Sage (prestige, permanent)
Flawless overflow (+2 stars): If you are at 3/4 stars in a tier and get a Flawless (+2), you fill the tier (4/4) AND the 1 extra star carries over into the next tier (1 star into the new tier).

Promotion Example — Apprentice (4 stars/tier)

1Start: Apprentice Tier 2, 3/4 stars
2Win a Victory (+1 star) → 4/4 stars → tier full
3Promote to Apprentice Tier 1, 0/4 stars
4Win another Victory (+1 star) → Apprentice Tier 1, 1/4 stars

▼ Demotion (Moving Down)

When you lose a star at 0 stars in a tier, you drop down one tier within the same rank:

  • Lose a star at Tier 2, 0 stars → drops to Tier 3 at (starsPerTier − 1) stars
  • Lose a star at Tier 3, 0 stars → stays at Tier 3, 0 stars (rank floor — cannot go lower)
  • You can never be demoted to a lower rank, only within tiers of your current rank

Demotion Example — Apprentice (4 stars/tier)

1At Apprentice Tier 2, 0/4 stars → Defeat (−1 star)
2Star goes to −1 → triggers demotion → drops to Apprentice Tier 3, 3/4 stars
3At Apprentice Tier 3, 0/4 stars → Defeat (−1 star)
4Rank floor hit → stays at Apprentice Tier 3, 0/4 stars (cannot drop further)
5 Star Protection Points (SPP) 🛡️

SPP are shield points that protect your rank stars from being lost on a Defeat. Maximum SPP = 3. They are displayed as shield icons on your profile.

Situation Effect on SPP Effect on Stars
Draw outcome +1 SPP No change
Defeat with SPP > 0 −1 SPP (permanently consumed) Star SAVED ✓
Defeat with SPP = 0 +1 SPP (starts rebuilding) −1 Star ✗
Important: Each shield is permanently consumed when used. With 3 shields, you can survive 3 consecutive Defeats without losing a star. The 4th Defeat (with 0 SPP) will cost you a star and give you 1 SPP back to start rebuilding.

SPP Timeline Example (starting with 3 SPP)

GameOutcomeSPP BeforeSPP AfterStars

2 Defeat 21 ★ Saved (shield used)
3 Defeat 10 ★ Saved (last shield used)
4 Defeat 01 ✗ Star LOST (−1 star)
5 Draw 12 No change
6 Draw 23 No change (back to full)
6 Star Bonus Points (SBP) 💎

SBP are diamond bonus points that can automatically upgrade your rewards when you perform well. Maximum SBP = 5. They are displayed as diamond icons on your profile.

Outcome SBP Gained
Flawless (natural) +1 SBP
Victory +1 SBP
Draw 0 SBP
Defeat 0 SBP

Auto-Redemption Rules

SBP is automatically spent before rewards are applied, in two scenarios:

Rule 1 — Victory Upgrade: If your game outcome is Victory AND you have 3 or more SBP, the system automatically spends 3 SBP and upgrades your rewards to Flawless level (+2 stars, +200 XP, +5 coins). This is called a "Bonus-Boosted" Flawless.
Rule 2 — Full-Cap Drain: If your game outcome is a natural Flawless AND your SBP is at the maximum cap of 5, all 5 SBP are drained to 0, allowing you to start rebuilding again.

SBP Bonus-Boosted Example

1Player wins 3 Victories in a row → SBP accumulates to 3
24th game: 5/8 correct = 500 pts = 62.5% → would normally be Victory
3SBP = 3 → auto-redeem triggers: spends 3 SBP → SBP drops to 0
4Rewards upgraded to Flawless: +2 stars, +200 XP, +5 coins
7 Profile XP & Level

Profile XP is completely separate from rank stars and never decreases. It tracks lifetime activity and unlocks profile levels. The XP required to go from level N to N+1:

XP needed for level N → N+1 = 100 + (N − 1) × 150

8 Full Worked Example
Starting State: Apprentice Tier 2 · 1/4 stars · SPP = 2 shields · SBP = 1 diamond · Profile XP = 530 · Coins = 83

Game 1 — 3/8 correct (all 1st attempt) → 300 pts → 37.5% → 🤝 Draw

→Rank stars: no change (still 1/4 stars, Apprentice Tier 2)
→SPP: +1 → now 3 SPP (full, capped at 3)
→XP: +60 → now 590 XP
→Coins: +1 → now 84 coins
→SBP: unchanged → still 1 SBP

Game 2 — 2/8 correct → 200 pts → 25% → ❌ Defeat

→SPP = 3 (greater than 0) → shield activates, consumes 1 SPP
→Rank stars: saved (still 1/4 stars)
→SPP: 3 → 2 SPP
→XP: +30 → now 620 XP
→Coins: +0

Game 3 — 6/8 correct (1st attempt) → 600 pts → 75% → ✅ Victory

→SBP = 1 (less than 3) → no auto-redeem, normal Victory
→Rank stars: +1 → now 2/4 stars in Apprentice Tier 2
→SBP: +1 → now 2 SBP
→XP: +120 → now 740 XP
→Coins: +3 → now 87 coins

Game 4 — 7/8 correct (1st attempt) → 700 pts → 87.5% → 🌟 Flawless

→SBP = 2 (less than 5) → no full-cap drain, normal Flawless
→Rank stars: +2 → 2 + 2 = 4/4 → tier full → PROMOTE to Apprentice Tier 1, 0/4 stars
→SBP: +1 → now 3 SBP
→XP: +200 → now 940 XP
→Coins: +5 → now 92 coins
